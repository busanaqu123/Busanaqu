Privacy Policy — BusanaQu Posting

Last updated: 18 November 2026

BusanaQu Posting accesses a user's TikTok account only after the user signs in and grants permission.

Data accessed: basic profile information (display name and avatar) to show the connected account, and the videos the user selects for posting.

This data is used only to operate the posting tool. It is never sold, never shared with third parties for advertising, and never used to access other users' accounts.

Access tokens are stored securely and only for as long as needed to provide the service. Users can revoke access at any time in TikTok Settings > Security and privacy > Apps and services, and may request deletion of stored data by contacting us.
